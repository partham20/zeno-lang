## `sort` with a function

```zeno
people.sort(function(person: Person) -> int { return person.age })
```

`sort` takes a function that says what each item is ordered by, a
number or text, so a list of anything can be put in order. Items
with the same key stay as they were. It is the same in `zeno run`,
the VM and both compilers, and with `--no-collector` it leaves
nothing behind.
[docs/library.md](https://github.com/partham20/zeno-lang/blob/main/docs/library.md)
walks through it.

## Mended

- A function given to `map`, `filter` or `reduce` that changed the
  list it was walking crashed `zeno run`. Built programs were right.
